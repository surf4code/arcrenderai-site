Architecture

Deterministic rendering from audio track to final MP4.

Instead of unpredictable frame-by-frame video diffusion, ArcRender compiles your script into version-controlled 3D code so every character, prop, and camera move stays consistent across 20-minute episodes.

01 / AUDIO INGEST

Word & Beat Alignment

Parses voiceover stems using forced alignment and acoustic RMS peaks to lock mouth phonemes, head nods, and impact camera punches to exact frames.

Output: alignment.json
02 / SCENE COMPILER

3D Diorama + 2D Rig Graph

Maps narrative beats onto modular React Three Fiber sets with cel-shaded lighting, 8 geometric character silhouettes, and comic FX layers.

Output: scene-manifest.ts
03 / SHARDED COMPUTE

Parallel Frame Workers

Splits long timelines into 15-second frame ranges rendered concurrently across stateless Linux headless Chromium nodes with retry recovery.

Runtime: AWS EC2 / Batch
04 / MASTERING

FFmpeg Stitch & Captions

Concatenates verified frame chunks, applies -14 LUFS loudness normalization, burns optional Shorts captions, and uploads the signed MP4.

Output: episode_master.mp4
